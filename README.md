## Abstract

Accurately measuring the sound field inside of a room purely from real-world data is extremely time-consuming, as it requires a large number of measurements and expensive equipment. In the past decade, several purely physics and signal-processing-based techniques have been proposed to predict the sound field inside a region from a limited number of data points. More recently, data-driven methods have also been proven to be powerful tools for this task. In this work, SFR3 is proposed, a sound field reconstruction diffusion model leveraging Super-Resolution via Repeated Refinement (SR3), which reconstructs the real and imaginary parts of the sound field from a grid of uniformly spaced microphones over a certain region. The model's performance is compared to a naive baseline consisting of a bicubic interpolation, a kernel-based method commonly used for this task, and a data-driven approach, showing that the proposed method outperforms the aforementioned techniques, especially at lower frequencies.

## Install & Usage

The model used in this research is based on this SR3 ([Super-Resolution via Repeated Refinement](https://ieeexplore.ieee.org/document/9887996)) implementation: "[Image-Super-Resolution-via-Iterative-Refinement
Public](https://github.com/Janspiry/Image-Super-Resolution-via-Iterative-Refinement)". Their code is contained in the "[sr3_modules](https://github.com/IoSR-Surrey/sfr3/tree/master/sr3_modules)" folder.

You can create the virtual environment and install the needed packages using conda with the following command: 

```
conda env create -f environment.yml
```

SFR3 is an SR3-based sound field reconstruction model capable of interpolating room transfer functions from a set of sensor measurements from a uniformly distributed grid. This is made possible by treating the sound field as a two-channel image and upscaling it through super-resolution, obtaining a more detailed sound field as the model output. This repository contains the code to train, run, and evaluate the model as well as the scripts necessary to generate and access the RTF datasets. 

The datasets can be generated by running the "[data.py](https://github.com/IoSR-Surrey/sfr3/blob/master/data.py)" script, which will use [pyroomacoustics](https://github.com/LCAV/pyroomacoustics) to simulate RIRs and obtain their relative RTFs, generating low and high-resolution microphone grids for training and evaluation. The new files are positioned in the "[datasets](https://github.com/IoSR-Surrey/sfr3/tree/master/datasets)" folder, indicating the initial and target resolution as well as the maximum considered frequency value in the range in its corresponding subfolder (.csv files, describing room layouts and their acoustic characteristics, are also produced to ensure reproducibility).

"[model.py](https://github.com/IoSR-Surrey/sfr3/blob/master/model.py)" instantiates SFR3, using classes and code from the "[sr3_modules](https://github.com/IoSR-Surrey/sfr3/tree/master/sr3_modules)" folder, automatically changing the U-Net's depth based on the target image resolution. It also prints out the parameter count of the model as well as its structure to terminal.

"[train.py](https://github.com/IoSR-Surrey/sfr3/blob/master/train.py)" performs the training process of the diffusion model, running a 5000-epoch run with a cosine LR schedule. The generated checkpoints are saved in the "[checkpoints](https://github.com/IoSR-Surrey/sfr3/tree/master/checkpoints)" folder, with subfolders indicating which dataset the model was trained on.

Finally, "[eval.py](https://github.com/IoSR-Surrey/sfr3/blob/master/eval.py)" performs the evaluation of the trained model, plotting its training run, comparing it to state-of-the-art baselines and computing their performance over a certain frequency range using the normalised mean squared error (the normalised cross-correlation is also computed as an extra metric to quantify spatial similarity of outputs with respect to the ground truth), as well as displaying the outputs of the different considered techniques.<br />
Baselines used in the evaluation section of the paper can be found in the "[complex_unet](https://github.com/IoSR-Surrey/sfr3/tree/master/complex_unet)" folder, adapted from the [original repository](https://github.com/RonFrancesca/complex-sound-field), and "[kernel.py](https://github.com/IoSR-Surrey/sfr3/blob/master/kernel.py)". While the kernel-based method is ready to use, the CVNN needs to be trained with the "[main.py](https://github.com/IoSR-Surrey/sfr3/blob/master/complex_unet/main.py)" script contained in the aforementioned directory.
